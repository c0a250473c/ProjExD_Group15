# シューティング

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1
* 必要なものがあれば追記してください（非推奨）

## ゲームの概要
* 宇宙が舞台
* 主人公キャラクターを操作し、弾を発射して敵を倒す。
* 参考URL：[サイトタイトル](https://www.hoge.com/)

## ゲームの遊び方
* 矢印キーorWASDで主人公を操作し，スペースキー押下による弾発射で敵を倒す。
* 敵の弾に当たったらゲームオーバーとなる

## ゲームの実装
### 共通基本機能
* 背景画像と主人公キャラクターの描画
* 分担追加機能以外の基本機能
### 分担追加機能

* スコア
* スコアによって能力向上
* ゲームオーバー画面

* 体力ゲージ
* 体力減ったら見た目がボロボロになる

* ボス(担当：中嶋)：
指定秒数(30秒)経つと、ボスが出現し、専用BGMが流れる。ボスは複数回(10回)弾を当てると倒せる。
* クリア画面（担当：中嶋）：
ボスを倒すとゲームクリアの画面が表示され、専用BGMが流れた後、終了する。
* アイテム（いろいろ）

* 敵の個性
* 特定の弱点

* デカい弾
* 打つとスタミナが減る
