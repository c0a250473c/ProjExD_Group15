# シューティングゲーム

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 宇宙が舞台のシューティングゲーム
* 敵の弾を避けながら攻撃し、アイテムやどでか弾も駆使して敵を倒す。
* 敵の弾に当たったら体力が減り、0になるとゲームオーバー。
* ボスを倒すとゲームクリアとなる。
* アイテムは4種類(回復,連射,無敵,スタン)
* ゲームの土台はGPT-6で作成
* 参考URL：
  - [Pygameドキュメント 日本語訳](https://westplain.sakura.ne.jp/translate/pygame/)
  - [Step104 【Pythonで縦スクロールシューティングを作る#3】：敵キャラクターを登場させる](https://note.com/stapa_pcschool/n/n0586afad2a8c)

## ゲームの遊び方
* 移動：矢印キーorWASD
* 攻撃：スペースキー
* アイテムの使用：Xキー
* どでか弾：Tキー

## ゲームの実装
### 共通基本機能
* シューティングゲームとしての基本機能↓
  - 主人公の移動と攻撃
  - 通常敵
  - 背景の設定
  - その他分担機能以外の機能
### 分担追加機能

* スコア表示（担当: 大西）：
左下にスコアを表示する。敵機を倒せば10点, 敵機の銃弾を撃ち落とした場合には1点を加算する。又、スコアが50点を更新する度に、弾の発射間隔が短くなる。
* ゲームオーバー画面（担当: 大西）：
HPが0になったとき、ゲームオーバー画面を表示する。その際、最終的なスコアを表示し、Rを押すことでリスタート、Qを押すことでそのまま終了する。

* 体力ゲージ（担当: 下地）：
残り体力に応じて体力ゲージの色が変わる。
残り体力が10になったら見た目がボロボロになり、煙の演出が追加される。


* ボス（担当: 中嶋）：
指定秒数(30秒)経つと、ボスが出現し、専用BGMが流れる。ボスは複数回(10回)弾を当てると倒せる。
* クリア画面（担当: 中嶋）：
ボスを倒すとゲームクリアの画面が表示され、専用BGMが流れた後、終了する。
* アイテム：アイテムは4種類。Xキーで使える。
  - スタン：蜘蛛の糸の見た目、今画面に映っている敵の攻撃を止める
  - 回復：フラスコの見た目、HPを回復する（最大HPの三分の一）
  - 連射：青いエフェクトの見た目、5秒間連射速度が速くなる
  - 無敵：黄色いスターの見た目、5秒間無敵状態になれる

* 敵キャラクター追加機能（担当: 吉野）：
普通の敵、ジグザグ移動する敵、大きなビームのみで倒せる敵を作成しました　

* どでか弾と鬱スタミナ（担当: 前川）：
キー入力: 指定されたキー(Tキー)を押すとデカイ弾を発射する
発動条件:スタミナが「50」以上残っていること、前回の発射から「0.5秒（500ミリ秒）」以上経過していること。
鬱状態（鬱スタミナ）の条件と効果:条件どでか弾などを撃って、スタミナ残量が「30未満」になる。ペナルティ効果:主人公の移動スピードが通常の「5」から「2」へと極端に遅くなる。また、スタミナゲージの色が緑色から紫色に変化して危険を知らせる。回復条件: スタミナは何もしなくても自動で少しずつ回復する。
